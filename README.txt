# Divine Branding Manager

A free, simple client/job manager built from your Divine Branding spreadsheet.

## What it includes
- Your existing client list pre-loaded
- Search clients
- Filter by status
- Add/edit/delete clients
- Due date, payment and notes
- Dashboard counts
- Export/import backups
- Works as a PWA when hosted over HTTPS
- Data is saved in the device browser using localStorage

## iPhone Home Screen
1. Put these files on a free HTTPS static host (for example GitHub Pages or Netlify).
2. Open the site in Safari.
3. Tap Share -> Add to Home Screen -> Add.

The app itself is free. It does not require a paid database or subscription for the basic version.
